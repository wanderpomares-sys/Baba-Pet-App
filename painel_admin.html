Configuração (só na 1ª vez neste navegador)

Use a service_role key do Supabase (Settings → API → "service_role"), NÃO a anon key. Ela lê tudo, então fica só neste navegador: nunca no app, nunca em repositório.

Os números valem para aparelhos novos (1º acesso dentro do período). Aparelho = um navegador/celular; limpar os dados do navegador gera um aparelho novo.
